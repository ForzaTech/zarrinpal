# 💳 ZarrinPal — Modern Payment Website

A modern, responsive, and visually appealing **ZarrinPal-inspired payment website** built from scratch using **HTML & CSS**. 🚀

This project focuses on creating a clean financial interface with a professional layout, responsive design, and a smooth user experience. ✨

---

## 🌟 Features

* 🎨 Modern & clean UI
* 📱 Fully responsive design
* 💻 Desktop, tablet & mobile support
* 💳 Payment-focused interface
* 🧭 Clean navigation
* ✨ Smooth visual effects
* 🖼️ Custom images & visual assets
* ⚡ Lightweight and fast
* 🧩 Organized project structure
* 🌐 Ready for static hosting

---
